# Contributing to Skaldsaga

Thank you for helping. Skaldsaga is free software under the [GNU Affero General Public License, version 3 or later](LICENSE), with the additional attribution terms in [`NOTICE`](NOTICE).

## Licensing rules for contributions

- **Your contribution is licensed AGPL-3.0-or-later.** By opening a pull request you agree that what you add is released under the project's license.
- **Everything you include must be either AGPL-3.0-or-later or under a license on the allowlist** in [`docs/security/license-policy.md`](docs/security/license-policy.md). That covers dependencies, code you copied or adapted, text, data and other assets, not just code you wrote.
- **Check before you add something.** Look up the license of any new dependency or copied material and compare it with the allowlist. If it is not on the list, do not add it; ask first. Unlisted licenses are decided one at a time by the author (research, then either add the license to the list or choose something else).
- **Say why in the pull request.** Each new dependency needs a one-line reason, and the pull request template asks you to confirm the license check.
- **Never remove or change** copyright, license or attribution notices in `LICENSE` and `NOTICE`, or in material you copy.

The allowlist is kept in one file on purpose. Do not copy it into other documents; link to it.

## Before you start

Read [`HANDOFF.md`](HANDOFF.md) (status and what is next) and [`CLAUDE.md`](CLAUDE.md) (build, test and security rules; it is written for Claude build sessions but the rules apply to everyone). The pull request template lists the checks every change needs.
